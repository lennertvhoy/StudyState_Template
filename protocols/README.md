# Protocols

Operating rules for the agent. `AGENTS.md` holds the contract and the loop; a
protocol holds the detail for one situation. Open a protocol when its situation
arises, not at session start (session start reads the context pack; see
`protocols/STATE_LOADING_POLICY.md`).

| Situation | Protocols |
| --- | --- |
| Starting or closing a session | [`START_SESSION`](START_SESSION.md), [`CLOSE_SESSION`](CLOSE_SESSION.md), [`SESSION_TEMPLATE`](SESSION_TEMPLATE.md) |
| Asking, grading, repairing | [`TUTOR_PROTOCOL`](TUTOR_PROTOCOL.md), [`ASK_QUESTION`](ASK_QUESTION.md), [`GRADE_ANSWER`](GRADE_ANSWER.md), [`QUESTION_QUALITY`](QUESTION_QUALITY.md), [`QUESTION_QUALITY_GOVERNOR`](QUESTION_QUALITY_GOVERNOR.md), [`MISTAKE_TAXONOMY`](MISTAKE_TAXONOMY.md) |
| Choosing what to do next | [`SELECT_NEXT_ACTION`](SELECT_NEXT_ACTION.md), [`LEARNING_ACTIVITY_POLICY`](LEARNING_ACTIVITY_POLICY.md), [`LOW_ENERGY_MODE`](LOW_ENERGY_MODE.md) |
| Reviews | [`SPACED_REPETITION_POLICY`](SPACED_REPETITION_POLICY.md), [`SCHEDULE_REVIEW`](SCHEDULE_REVIEW.md) |
| Writing and loading state | [`UPDATE_STATE`](UPDATE_STATE.md), [`STATE_WRITE_POLICY`](STATE_WRITE_POLICY.md), [`STATE_LOADING_POLICY`](STATE_LOADING_POLICY.md), [`PERFORMANCE_POLICY`](PERFORMANCE_POLICY.md) |
| Readiness | [`READINESS_POLICY`](READINESS_POLICY.md) |
| Sources | [`SOURCE_TRUST`](SOURCE_TRUST.md), [`SOURCE_FRESHNESS_POLICY`](SOURCE_FRESHNESS_POLICY.md), [`SOURCE_REFRESH_POLICY`](SOURCE_REFRESH_POLICY.md), [`RECORD_SOURCE_CHECK`](RECORD_SOURCE_CHECK.md) |
| Work done outside the chat | [`EVIDENCE_INTAKE_POLICY`](EVIDENCE_INTAKE_POLICY.md), [`EXTERNAL_RESOURCE_POLICY`](EXTERNAL_RESOURCE_POLICY.md), [`VOICE_NOTE_REVIEW_POLICY`](VOICE_NOTE_REVIEW_POLICY.md), [`INTERVIEW_PREP_POLICY`](INTERVIEW_PREP_POLICY.md), [`PRESENTATION_PREP_POLICY`](PRESENTATION_PREP_POLICY.md) |
| Adapting to the learner | [`LEARNER_ADAPTATION_POLICY`](LEARNER_ADAPTATION_POLICY.md), [`LEARNER_FEEDBACK_POLICY`](LEARNER_FEEDBACK_POLICY.md) |
| Creating, upgrading, or recovering a repo | [`INSTANTIATE_TEMPLATE`](INSTANTIATE_TEMPLATE.md), [`UPGRADE_INSTANCE_FROM_TEMPLATE`](UPGRADE_INSTANCE_FROM_TEMPLATE.md), [`TEMPLATE_INSTANCE_BOUNDARY`](TEMPLATE_INSTANCE_BOUNDARY.md), [`WRONG_REPO_RECOVERY`](WRONG_REPO_RECOVERY.md), [`GIT_PROVENANCE`](GIT_PROVENANCE.md), [`PRIVACY_REVIEW`](PRIVACY_REVIEW.md) |

[`docs/worked-state-update.md`](../docs/worked-state-update.md).
