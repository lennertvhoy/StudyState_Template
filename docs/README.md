# Docs

Guides for people and agents. The agent's contract is `AGENTS.md`; the operating rules
for one situation each are in `protocols/` (index: `protocols/README.md`).

## Start here

- [`agent-native-quickstart.md`](agent-native-quickstart.md): cast an instance and run a first session.
- [`setup.md`](setup.md): Python, a virtual environment, and dependencies, on Linux, macOS, and Windows. Nothing installs without consent.
- [`demo-walkthrough.md`](demo-walkthrough.md): the public demo replay, step by step.
- Per-agent tips: [Codex](how-to-use-with-codex.md), [Claude Code](how-to-use-with-claude-code.md), [Kimi Code](how-to-use-with-kimi-code.md), [Cursor](how-to-use-with-cursor.md).
